# FirstSky

**Fully local, free, and API-less Reddit story to vertical short video generator.**

Turn popular Reddit posts into high-quality TikTok / YouTube Shorts style videos **completely offline**.

---

## ✨ Features

- Completely local (no API keys needed)
- Smart Reddit post scraping & ranking
- Natural Text-to-Speech narration (local + Edge TTS support)
- Automatic B-roll footage, background music, and stylized subtitles
- Clean modern terminal UI
- Outputs ready-to-upload 9:16 MP4 videos
- Multiple tools: PTK, FFV, and ORL

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/notyetaperson/First-sky.git
cd First-sky

# Install dependencies

# Run the program
